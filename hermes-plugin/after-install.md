# godspeed-stickers is installed

Two more steps:

1. Tell your agent when to use a sticker. Add this to its instructions (for example in
   `~/.hermes/SOUL.md`):

   > When you finish something I asked for, end your reply with `[[sticker:done]]`.
   > When you need my yes on something, end it with `[[sticker:copy]]`.

2. Restart the gateway: `hermes gateway restart`

All seven tags and the optional settings are in the plugin's README.
